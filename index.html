One-time Google setup
  1. On a computer open console.cloud.google.com and create a project called “Party Machines Booth”.
  2. Go to APIs & Services → Library, search Google Drive API and click Enable.
  3. Go to OAuth consent screen (Google Auth Platform): choose External, enter an app name and your email, and under Test users add your own Google email.
  4. Go to Credentials → Create credentials → OAuth client ID, type Web application. Under Authorized JavaScript origins add https://partymachinessa.github.io.
  5. Copy the Client ID it shows and paste it above.
